# Agent Note: Preview 跟随 agent 写入

Status: implemented

[English](2026-09-16-preview-follows-agent-writes.md) | 中文

## Problem

文档预览过去只提示变更、不应用变更：读者没做过的写入会在已加载内容之上亮出一条提示，等待点击。该规则是为了在 agent 反复写入同一文件时保住读者的位置而定的，并[随已交付的预览一并记录](2026-09-05-sidebar-text-preview-and-file-tree.zh.md)。

对于 agent 正在处理的文件，这条规则的代价大于它保护的东西。盯着 diff 的读者没有未保存的工作可丢：正文只是查看器，待显示的内容在磁盘上早已被取代。提示条迫使他们去取产品明知已经过期的内容；而在他们点击之前，任何把变更元数据叠加到正文上的渲染器——dsh-striatum 经 document 座位贡献的改动审查视图——会用新的行号画在旧正文上，因为观察带来的是新版本，而已加载页面属于上一个版本。

## Decision

不是本 tab 所做的写入会自行重读。`TextPreview` 把已加载版本、该次读取开始时的观察版本，与 `useResource<'file'>` 后续给出的 `WorkspaceFileStat.version` 比较；不同就通过页头控件所用的同一个 face 安排一次 `reload`。资源模型、预览 face 与 store 都没有新增东西。

四条规则约束这次自动读取：

- **先等观察停止到达。** 一个 agent turn 可能多次写入同一文件，每次写入都会发出一次 Host 观察。重读在最后一次观察之后 200 ms 运行，于是一阵写入变成反映其最终状态的那一次读取。
- **只有可见的 tab 读取。** 该 effect 由 `useTabInfo().tab.visible` 把关：收起的 Sidebar,或活动 tab 是另一个的 pane,会保留内容直到读者能看见它，然后再读。不为无人查看的文件做读取，也不扰动隐藏状态的滚动位置。
- **元数据失败优先于变更。** 失败行保留由读者主动点击的重读，不会在其上运行自动读取。
- **渲染器自己的写入立即生效。** 写了该文件的体经 `reload` owner prop 上报（[文档预览操作](../architecture/2026-09-08-document-preview-operations.zh.md)）；等待窗口从不拖延它。

变更提示条及其 `changed` 文案已移除：它提供的重读如今就是默认行为，页头中的重新载入控件仍留给想要手动重读的读者。

重读会在第一页返回前清空正文，而没有高度的滚动容器会把自己的偏移夹到零并上报该移动。正文的滚动处理在有内容之前忽略滚动事件，因此读者记录的位置能挺过这段窗口——否则浏览器会用那个零把它覆盖掉。

## Alternatives considered

**保留提示条并让它更显眼。** 缺陷不在于提示条容易被忽略，而在于一个查看器竟然要征求许可才显示当前内容。更醒目的提示条会继续保留过期文本与错位的叠加层。

**每次观察都重读。** 一个 turn 里写五次就会重读五次，让正文在四个早已被取代的中间状态间闪烁。读者关心的是这一阵写入的结果，不是单次写入。

**所有 tab 都读，不论是否可见。** 后台 tab 的读取是无人要求的开销，其结果还会在读者没看的内容下移动滚动位置。等到可见再读，能在内容真正可用的一刻交付同样的内容。

**用 path row 的滚动偏移来保住读者位置。** 正文已经把偏移记录在 tab store 里，并在重读后恢复它；唯一覆盖它的是收起滚动容器上报的那个零。忽略那次上报即可修好，无需第二个位置来源。

**只重读已加载范围，而不是从第一行开始。** 重读会从第一页开始，因此超过分页上限的文件会丢掉读者已滚动到的页面。保留范围需要在 face 与 store 中新增一条读取路径；而大到需要分页的文件，其变更元数据也最不可能一屏放下。这里记为暂缓而非否决：在出现需要保留范围的场景之前，自动读取继续复用既有路径。

## Consequences

盯着 agent 正在编辑的文件的读者无需请求即可看到当前内容，在该文件上叠加变更元数据的渲染器也与它绘制的正文对齐。提示条文案及其字典键已从包中移除。

自动读取覆盖不到 Host 本就存在的边界：`fs/observed` 由被插桩的文件系统操作发出，因此 agent 通过 shell 命令写入，或产品之外的编辑器改动，都不产生观察、也不产生读取。那种情况下预览并非疏于跟进，而是从未被告知。页头的重新载入控件仍是那里的答案，观察契约由 [Workspace Files 服务](../architecture/2026-09-05-workspace-files-service.zh.md)拥有。

超过 Host 分页上限的文件会从其第一行重读，因此已滚动过数页的读者会回到自动读取所取的那些页面。验证为 `packages/client/ui-sidebar-documentpreview/tests/text-preview.client.spec.tsx`——它钉住自动读取、合并窗口、隐藏 tab 的等待，以及读者保住的位置；以及 `tests/document-seat.client.spec.tsx`——它钉住写入渲染器的立即重读。
